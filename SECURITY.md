# Security Policy

## Supported versions

Only the latest release of MistvaleRPG receives fixes.

## Reporting a vulnerability

Please do **not** report security problems in a public issue.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**, or open the form directly at
<https://github.com/NebulanEnt/mistvale-rpg/security/advisories/new>.

Examples of things worth reporting: crashes or exploits that can be triggered remotely on a server by a normal player, packet handling that trusts client data, or commands that can be abused without permission.

You can expect a first reply within about a week. Please give some time for a fix before sharing details publicly.
