# Contributing to MistvaleRPG

Thank you for caring about Mistvale. Here is how you can help, and what to expect.

## Code contributions

MistvaleRPG is a personal learning project. All of its code is written by hand by the author, and that is part of the point of the project. For that reason **pull requests that change code are not accepted**, and unsolicited ones will be closed politely without review. The only exception is a tiny fix to a typo in documentation or a language file.

This is not a judgement on anyone's skill. If you spot a problem in the code, please describe it in an issue instead, and the fix will be made by the author.

## Ways you can help

- **Report bugs.** Use the [bug report form](https://github.com/NebulanEnt/mistvale-rpg/issues/new/choose). Include your Minecraft, NeoForge and GeckoLib versions, what you did, what you expected, what happened, and the `latest.log` if the game crashed.
- **Suggest ideas.** Story, quests, mobs, rifts, anything. Start a [discussion](https://github.com/NebulanEnt/mistvale-rpg/discussions) or use the feature request form.
- **Give art and sound feedback.** Notes on readability, colours and animation timing are very welcome.
- **Fix typos in text.** If you find a spelling mistake in the language files or documentation, a small pull request or an issue pointing to it is fine.

## Before you open an issue

1. Search existing issues and discussions to avoid duplicates.
2. Test with only NeoForge, GeckoLib and MistvaleRPG installed, if you can. If the bug only appears next to another mod, say which.
3. One problem per issue, please.

## Your contributions and rights

Anything you post here (reports, ideas, screenshots) is shared voluntarily to help the project. The project license in [LICENSE](LICENSE) still applies to the repository itself.
